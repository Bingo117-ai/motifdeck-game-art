# MotifDeck: AI sprite animation for 2D games

MotifDeck is an AI game art workspace for 2D characters and motion. Instead of hand-posing a handful of frames, it generates the whole move as continuous video first, so capes, hair and cloth follow through, then extracts the frames, cleans up the background and lets you keep your own selection, order and timing.

- Video-first sprite animation: the motion is generated as video, then cut into frames
- Automatic background cleanup and one-click recolor variants
- Up to 16 frames on Free, Starter and Creator, or 64 on Pro and Studio
- Export PNG frames, sprite sheets, GIF or ZIP

Free accounts start with 50 one-time Credits. Try it at https://motifdeck.com/ — no install, runs in the browser.
